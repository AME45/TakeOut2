🔴 严重 Bug
1. DishController.java:111-114 — redisTemplate.delete() 不支持通配符

private void CleanCache(String pattern){
    String keys = pattern;
    redisTemplate.delete(keys);  // ❌ 传 "dish_*" 进去删不掉任何缓存！
}
redisTemplate.delete(key) 是精确匹配，你传 "dish_*" 它会去找一个名字真的叫 "dish_*" 的 key，找不到就啥也不删。删除和启停时缓存根本没被清掉喵！

修复：


private void cleanCache(String pattern) {
    Set keys = redisTemplate.keys(pattern);
    if (keys != null && !keys.isEmpty()) {
        redisTemplate.delete(keys);
    }
}
